Bank Sync & E-Invoice ​

概述 ​

銀行同步與**載具（電子發票）**為會員限定進階功能。銀行端以 Android 原生自動化為主；載具查詢改由 backend 代理財政部 API，前端 wizard 引導驗證與匯入。

isEInvoiceApiConfigured() 必須同時有 API base 與 client key；非 web／PROD 無 key 不得再回 true。

playwright:bank-sync 已納入 CI。第一銀行 Phase 0C 真機 overlap、華南 H1/H2 登入後 DOM 尚未用真機證明。見 Sync Architecture B、Native Bank APK。

載具 / 電子發票 ​

流程 ​

  1. Step 1：手機條碼 + 查詢碼驗證
  2. Step 2：日期區間查詢（預設最近 62 天）
  3. 選取發票 → 可選帳戶 / 分類 → 建立支出交易

Backend 代理：/api/einvoice/query-invoices（詳見 repo einvoice 路由）

前端 wizard：frontend/src/ui/views/einvoice/

可用性面板 ​

資格 → 平台 → API health → 憑證 → captcha → 同步 → 審核；captcha 可刷新 / 取消 / 到期提示。

同步合約自檢（Backend） ​

backend/scripts/sync-contract-check-run.mjs 編排載具 + 銀行 portal 錨點探測，CI cron 與主機腳本共用，避免外部 HTML 結構漂移導致 silent break。

與其他域 ​

  • Membership：功能 gating
  • Bookkeeping：匯入結果寫入 transactions
  • Settings：進階功能入口在 FeatureListPage.vue
