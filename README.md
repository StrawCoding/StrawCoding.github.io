# StrawCoding.github.io

Organization GitHub Pages root. Serves redirects to project documentation:

- [StrawMoneyBook Wiki](https://strawcoding.github.io/StrawMoneyBookWiki/)

Legacy URLs without the `/StrawMoneyBookWiki/` prefix (e.g. `/operations/playwright-app-shell.html`) are handled by `404.html` and forwarded to the VitePress site.
