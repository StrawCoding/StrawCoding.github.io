ARCHITECTURE & DOCUMENTATION ​

StrawMoneyBook 開發者手冊：monorepo 架構、本機 SQLite 與 Capacitor 執行期、共同帳本 API、Google／WebDAV 同步、Android 原生銀行 WebView、發版與 PolyForm 非商用開源 授權邊界。

開源授權安裝入門本機開發同步備份銀行載具Play 發版分層架構故障排查

01 · 入門、開源與環境 ​

01.1LICENSEOpen Source & License

PolyForm Noncommercial：公開原始碼、禁止第三方商用；fork 義務、官方 Play 與社群自建邊界。

01.2STARTQuick Start

Clone、npm 安裝、預設連 api.strawmb.com 的前端 dev；本機 backend 8787 覆寫方式。

01.3DEVLocal Dev Quickstart

維護者日常：ports、進階功能入口、test / check 指令與常見陷阱。

01.4ENVEnvironment Variables

VITE_* 與後端 env 對照；.env.example；禁止提交 secret／keystore。

01.5AUTHAuthentication

Google Sign-In、server auth code、backend OAuth exchange；與自動備份重新授權。

01.6SECURITYAuth & Security Ops

App 安全鎖、session、rate limit、production env 檢查清單。

02 · 功能域與資料流 ​

02.1DOMAINBookkeeping

AI／手動／問答記帳、交易列表、搜尋與 home 篩選 composable。

02.2DOMAINBudget

月預算、分類預算、日均規則、發薪週期與共同池。

02.3DOMAINAnalysis & Reports

分類／帳戶／時間柱狀分析、PDF 匯出、SQL 彙總路徑。

02.4SYNCSync, Backup & Shared Ledger

GDrive 帳本同步、WebDAV 自動備份、共同帳本快照與衝突策略。

02.5NATIVEBank Sync & E-Invoice

Android WebView 原生銀行自動化、載具 API、Arch B runbook 入口。

02.6ANDROIDAndroid & Capacitor

Capacitor 8 插件、Wear 伴侶、widget 與 build 管線概覽。

03 · 發版、測試與營運 ​

03.1RELEASERelease Process

版本 a.b.c.d、npm run gpr、tag 與 Play internal／production 通道。

03.2TESTTesting & Verification

Node test、smoke、禁止新增 source-only 測試的政策與替代方案。

03.3E2EPlaywright App Shell

UI 改動驗收、bootstrap pageerror、現代／傳統 layout 雙軌。

03.4APKNative Bank APK

銀行同步 Java 變更必須重建 release APK；與 web-only deploy 的差異。

03.5DEPLOYBackend Deploy & Health

deploy:copy、Docker StrawMB、container 內 native 依賴陷阱。

03.6FORENSICSTroubleshooting

OAuth、同步、銀行 captcha、CI 與 Play 常見失敗模式索引。

04 · 架構與核心模組 ​

04.1COREArchitecture Overview

本機優先、backend 協作邊界、mermaid 系統圖與技術棧表。

04.2LAYERSApplication Layers

ui/ vs core/ 依賴方向、Store／Service／Repository 職責。

04.3DATAData Model & Storage

SQLite schema 概念、帳本 lifecycle、migration 注意事項。

04.4UIFrontend Stack

Vue 3、Pinia、Habitat layout、i18n 與路由模組化。

04.5APIBackend API

共同帳本 REST、session cookie、collab-store 檔案位置。

04.6RUNTIMEStartup & Runtime

App 啟動鏈、store hydration、跨日發薪週期 rollover 觸發點。
